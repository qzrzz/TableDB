# 目录树 | Tree

目录树（Tree）是 TableDB 的一个扩展功能，提供了树形结构的数据管理能力。通过目录树扩展，你可以得到一个功能完善的树形数据结构，支持节点的创建、查询、更新、删除、移动、复制等操作，它会自动维护目录树功能的元数据。

## 概念

### 节点修改计数 `modif`

目录树中的每个节点都有一个 `modif` 字段，表示该节点的修改计数。每当节点被修改时，`modif` 值会自动递增。通过 `modif` 字段，你可以简单的判断一个节点是否被修改过。

与 Table 自动维护的 `_updateDate` 不同，`modif` 是在可控的，根据业务逻辑可以选择性地修改 `modif`。

`modif` 包含了系统的修改和用户的修改，所以它不应该作为给用户看的「更新时间」，比如 index 排序

### 可控排序 `index`

目录树中的每个节点都有一个 `index` 字段，表示该节点在同级节点中的排序位置。`index` 是一个分数索引（Fractional Indexing），它可以在排序时仅修改当前节点而不改变其他节点的 `index` 值，从而实现高效的排序操作。其代价是它是一个字符串类型，体积会较大。

为了避免不需要 `index` 时不占用体积，`index` 默认是空字符串，只有需要时才会设置。
